# Платформа генерации гитарных табулатур с использованием искусственного интеллекта

Данный репозиторий является основным репозиторием выпускной квалификационной работы на тему:

**«Разработка платформы генерации гитарных табулатур с использованием искусственного интеллекта»**

Автор проекта: **Кошелев Алексей Игоревич**, студент **КНИТУ-КХТИ**, группа **4321-22**.

## О проекте

Проект представляет собой веб-платформу для генерации гитарных табулатур с использованием методов искусственного интеллекта. Система позволяет пользователю пройти авторизацию, выбрать жанр, сгенерировать табулатуру, просмотреть результат, сохранить его в личном кабинете и управлять своими данными.

Архитектурно проект состоит из трёх основных частей:

- **client** — фронтенд на React + TypeScript;
- **server** — backend на Spring Boot;
- **ml_server** — ML-сервер на Python/FastAPI для генерации табулатур и аудио.

Все части находятся в одном репозитории и работают как единая система.

## Основные возможности

- регистрация и авторизация пользователей;
- восстановление и смена пароля;
- просмотр главной страницы, страницы «О проекте», профиля, списка табулатур и конкретной табулатуры;
- генерация табулатуры по выбранному жанру и входным данным;
- сохранение и удаление табулатур;
- хранение и выдача данных пользователя через backend;
- взаимодействие backend с ML-сервером;
- генерация табулатуры и экспорт результата в текстовый формат и аудио;
- наличие автоматических тестов для frontend, backend и ML-сервера.

## Структура репозитория

### `client`
Папка `client` содержит фронтенд часть проекта.

Основной стек:
- React;
- TypeScript;
- Vite;
- Vitest;
- CSS.

Что находится внутри:
- `src/pages` — страницы приложения;
- `src/components` — переиспользуемые компоненты интерфейса;
- `src/router` — маршрутизация и защита приватных/публичных маршрутов;
- `src/store` — глобальное состояние;
- `src/api` — слой работы с backend API;
- `src/hooks` — пользовательские хуки;
- `src/utils` — вспомогательные функции;
- `src/tests` — тесты на Vitest;
- `markup` — статические HTML-макеты и связанные с ними изображения, стили и аудио;
- `public` — публичные статические файлы.

Фронтенд отвечает за пользовательский интерфейс, отображение страниц, отправку запросов на backend и показ результата генерации.

### `server`
Папка `server` содержит backend часть проекта на Spring Boot.

Основной стек:
- Java;
- Spring Boot;
- Spring Security;
- REST API;
- Maven;
- PostgreSQL.

Что находится внутри:
- `controller` — REST-контроллеры;
- `service` — бизнес-логика;
- `repository` — доступ к данным;
- `entity` — сущности базы данных;
- `dto` — объекты запросов и ответов;
- `security` — JWT-аутентификация и настройки безопасности;
- `integration` — клиент для связи с ML-сервером;
- `config` — конфигурация приложения;
- `exception` — обработка ошибок;
- `src/main/resources/schema.sql` — схема базы данных;
- `src/test` — тесты backend-части.

Backend отвечает за:
- авторизацию и регистрацию;
- работу с пользователями;
- работу с жанрами;
- создание, получение, сохранение и удаление табулатур;
- восстановление пароля;
- защиту API;
- связь с ML-сервером.

### `ml_server`
Папка `ml_server` содержит сервер машинного обучения.

Основной стек:
- Python;
- FastAPI;
- PyTorch;
- pytest.

Что находится внутри:
- `core` — логика генерации соло;
- `preprocessing` — предобработка входных данных;
- `export` — экспорт результата в текст и аудио;
- `assets/audio` — подготовленные аудиоданные по жанрам;
- `models` — обученные модели для жанров;
- `constants` — музыкальные константы;
- `bin/unix` — дополнительные бинарные файлы `ffmpeg` и `ffprobe`;
- `tests` — тесты ML-сервера.

ML-сервер получает запрос от backend, генерирует табулатуру и возвращает результат в удобном для дальнейшей обработки виде.

## Как работает система

1. Пользователь взаимодействует с фронтендом.
2. Фронтенд отправляет запросы на backend.
3. Backend выполняет проверку данных, авторизацию, работу с БД и при необходимости обращается к ML-серверу.
4. ML-сервер генерирует табулатуру и, при необходимости, аудиофайл.
5. Backend возвращает результат на фронтенд.
6. Фронтенд отображает итог пользователю и позволяет сохранить результат.

## Запуск проекта

Ниже приведён общий порядок запуска. Точные команды могут зависеть от окружения и настроек подключения к базе данных и ML-серверу.

### 1. Backend
Перейти в папку `server` и запустить Spring Boot-приложение.

Пример:
```bash
cd server
./mvnw spring-boot:run
```

### 2. ML-сервер
Перейти в папку `ml_server`, установить зависимости и запустить FastAPI-приложение.

Пример:
```bash
cd ml_server
pip install -r requirements.txt
uvicorn main:app --reload
```

### 3. Frontend
Перейти в папку `client`, установить зависимости и запустить Vite-приложение.

Пример:
```bash
cd client
npm install
npm run dev
```
